# Client onboarding readiness 026

1. Apply `supabase/migrations/026_client_onboarding_readiness.sql` once in the Supabase SQL Editor.
2. Run `npx next typegen && npx tsc --noEmit`.
3. Refresh the Platform page and open a business.
4. Select `Onboarding readiness` and complete any pending items.

A business is ready when it is active and all six items are complete: contact profile, logo, valid subscription access, at least one module, an active main branch and an active client administrator. This phase only assesses existing data; it does not automatically change client settings.
